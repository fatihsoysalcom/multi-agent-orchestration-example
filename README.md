# Multi Agent Orchestration Example

This example demonstrates the core concept of multi-agent orchestration in AI applications. An `OrchestratorAgent` delegates a complex request to specialized `SummarizerAgent` and `QuestionAnswererAgent` instances, simulating how different AI agents collaborate and combine their outputs to fulfill a task. It highlights task distribution, inter-agent communication, and sequential processing without requiring external LLM APIs.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
